# Offline Student Management System

A single integrated UWP and C# application for offline student academic information and service requests.

## Required flow

Login → OnCanvas → Student Hub → Academic Pivot, Fees, and Student Services → Logout

## Run in Visual Studio

1. Open `OfflineStudentManagementSystem.sln` in Visual Studio 2022 on Windows.
2. Install the Universal Windows Platform development workload and Windows 10 SDK 19041 if Visual Studio requests them.
3. Select x86 or x64 and Local Machine.
4. Build and run the solution.

The application uses local sample data and does not require an internet connection.
